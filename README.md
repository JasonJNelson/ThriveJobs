# ThriveJobs

AI-powered job search landing page built exclusively for job seekers.

## Features
- Modern dark UI with green accent
- Hero + interactive applications dashboard mock
- Feature grid, How it works, Pricing (cheaper than competitors), Comparison table, Testimonials
- Fully responsive single-page HTML (no build step)

## Pricing (demo)
- **Free** — $0 · 10 applications/month
- **Starter** — $9/mo · 50 applications
- **Pro** — $19/mo · 150 applications (Most popular)
- **Unlimited** — $39/mo · Unlimited

## Live preview
Open `index.html` in any browser, or enable **GitHub Pages**:
1. Go to Settings → Pages
2. Source: Deploy from a branch → `main` / root
3. Your site will be at: https://jasonjnelson.github.io/ThriveJobs/
